# チームの企画資料を置く

前段でチームがまとめた企画を、この`docs/`直下へ追加します。PDF・画像・Markdownなど形式もファイル名も自由です。UI画像やFigmaは必須ではありません。

TMU Campus Jamでは、ワークシートで決めた内容を`docs/worksheet.md`（テンプレートを用意済み）にまとめます。画像やPDFを追加で置いても構いません。

- Codespaces：作業ブランチを開き、Explorerの`docs`へファイルを追加します。
- Copilot app：開いているチームプロジェクトのフォルダをOSで開き、`docs`へコピーします。
- GitHubでアップロードする場合：班のリポジトリの**作業ブランチ**で`docs`を開き、**Add file → Upload files**。保存後は編集環境で同じ枝をPullします。

Publicリポジトリへ置いてよい内容だけを使い、個人情報や秘密の値は除きます。CopilotのPlanには、実際に置いたファイルを`docs/企画.pdf`などのパスで指定します。読み取れない部分は本文の貼り付けや読み取れる形式で補い、内容を推測させません。

準備できたら[READMEのPlan](../README.md#plan)へ進みます。計画や進捗のひな形をここへ追加する必要はありません。合意後にCopilotへルートの`PLAN.md`の保存・確認を依頼し、自分たちでも実ファイルを開いて内容を確認してから実装へ進みます。進捗と確認結果は実装時に`PROGRESS.md`へ残します。
